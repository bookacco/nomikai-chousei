# 飲み会調整

日程（○△×）と企画テーマ（いいね複数選択）を1画面で集める、調整さん風のページです。
画面は GitHub Pages、回答の保存は Google スプレッドシート（GAS）です。

## 1. スプレッドシートと GAS の準備（5分）

1. Google ドライブで新しいスプレッドシートを作る（名前は「飲み会調整」など）
2. メニュー「拡張機能」→「Apps Script」を開く
3. 最初からある `コード.gs` の中身を全部消し、`Code.gs` の中身を貼り付けて保存
4. 右上「デプロイ」→「新しいデプロイ」
   - 種類：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」→ Google アカウントの権限承認（「詳細」→「安全ではないページに移動」で進める）
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピー

## 2. ページの設定

`index.html` の上の方にある `CONFIG` を書き換えます。

- `title` / `note`：タイトルと説明文（締切など）
- `gasUrl`：手順1でコピーした URL
- `dates`：候補日
- `themes`：企画テーマ（`note` は小さく出る補足。空でもOK）

`gasUrl` が空のままだと「デモモード」になり、送信内容は保存されません（見た目の確認用）。

## 3. 公開

GitHub のリポジトリで Settings → Pages → Branch を `main` / `(root)` にして保存。
数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。この URL を LINE で共有してください。

## 補足

- 同じ名前で送り直すと上書きされます。名前を入れると前回の回答が自動で読み込まれます。
- 集計は「×が1人もいない日程」の中で、○=2点・△=1点の合計が最も高い日を緑で表示します。
- 回答はスプレッドシートの「回答」シートにそのまま並ぶので、幹事が直接直すこともできます。
- GAS のコードを直したときは「デプロイを管理」→ 編集 →「新バージョン」で更新します（URL は変わりません）。
- URL を知っていれば誰でも回答・閲覧できます。友人内での利用を前提にしています。
